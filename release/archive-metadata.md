# Archive and repository metadata

Title: Sustained Selected Complex Receive Streaming from the BCM43455 on Raspberry Pi 5

Author: Adam Davies. Repository: https://github.com/TheOddSock/pi5-wifi-sdr

Version: 0.3.0. Resource type: technical report. Language: English. Evidence selected through 6 October 2026.

Description: Inspired by ESP-SDR, this project adapts the Raspberry Pi 5's existing BCM43455c0 diagnostic collector into sustained, checked delivery of selected complex receive samples to Linux. An audited one-hour recording contains 3,000,238,080 complex words. Separate controlled-source bursts and historical finite Wi-Fi decodes provide distinct reception evidence. Source-only recipes reproduce the tested firmware and driver builds. Comprehensive filtering, RF calibration and continuous decoding remain further work; manufacturer binaries, ambient recordings and the acquisition controller are excluded.

Keywords: BCM43455; CYW43455; Raspberry Pi 5; receive samples; firmware; SDIO; complex samples; reproducible research.

Repository description: Experimental radio-sample streaming from the Raspberry Pi 5's Wi-Fi chip, with an audited one-hour recording, reproducible builds and documented receiver limits.
