# Device implementation availability
The implementation turns an existing finite diagnostic collector into sustained, checked radio-sample export to Linux on Raspberry Pi 5/BCM43455c0. It shares ESP-SDR's broad sample-access idea, including existing continuous Wi-Fi-chip SDR work. The demonstrated one-hour stream is an experimental capability; comprehensive filtering, calibrated tuning/bandwidth and continuous decoding still need work before a practical general-purpose receiver is established. [Project explanation](../README.md#what-this-project-achieves).

The [source-only device package](device/README.md) contains the exact native append, minimal kernel patch and additions, portable build/reconstruction scripts, pinned input hashes, upstream notices and component rights map. Fresh offline/native and unprivileged kernel builds reproduce the complete tested b4b image and d437 module bytes. No proprietary image or compiled module is included. Original project code now uses GPL-2.0-or-later through the outer [licence grant](../LICENSING.md) and [exact file map](../release/component-licences.csv); existing upstream terms remain applicable. Device source code and original build receipts retain their bytes; package documentation and inventories have been refreshed for this release.

The tested full operational controller is withheld because it depends on private freshness, installation, recovery and health records. This package reconstructs software; it does not install a radio receiver or provide a turnkey hardware experiment. Read [integration prerequisites](device/INTEGRATION.md) before planning hardware reproduction. Offline protocol and frame tools remain in tools/.

The separate [ABI37 source package](device-abi37/README.md) and [build instructions](device-abi37/BUILD.md) reproduce the complete 58a native image and 44c module with pinned reader-supplied inputs.
