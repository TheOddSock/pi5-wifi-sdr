Publication checklist

• Confirm the public author names, actual contributions and canonical repository URL.

• Confirm included attribution, third-party notices, input boundaries and the exact file licence map.

• Verify the exported tree excludes private recordings, credentials and proprietary binaries.

• Run tests, metrics, frame checks, file-manifest verification and static-site link verification.

• Inspect the PDF, desktop and mobile page; confirm the downloadable PDF matches the report asset.

• Bind the exact files and checksums and obtain approval for that release and destination.

• Publish the repository, versioned assets and static page; verify them as an unauthenticated reader.

• Record actual availability, identifiers and immutable release checksums. Retain previous versions.

The manifest records preparation and approval separately. Rendering a release-labelled report does not mark the package as approved or published.
